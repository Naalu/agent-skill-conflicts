\section{Background and Related Work}
\label{sec:background}

\textbf{How agents select skills.} A skill is a folder with a SKILL.md file whose YAML front matter holds at least a name and a description~\cite{agentskillsspec}. The agent shows the model only the names and descriptions and loads the full text of the skill the model picks; a skill with \code{disable-model-invocation: true} is never shown~\cite{claudecodeskills}. Each product reads its own directories. As documented in July 2026, Claude Code reads \code{.claude/skills} and Codex reads \code{.agents/skills}, while Copilot and Cursor read several directories at once~\cite{claudecodeskills,codexskills,vscodeskills,cursorskills} (Table~\ref{tab:dirs}). When two skills share a name, Claude Code prefers a personal skill over a project skill, and Codex lists both; the user is not told when either rule applies.

\textbf{Skill selection under competition.} Choosing among similar options is a known problem for tool-using LLMs~\cite{huang2024metatool,qin2024toolllm}. For skills, adding near-synonym competitors cut selection accuracy by up to 63\%~\cite{li2026singleagent}, and when two same-job skills are loaded together, rule-following drops from 93 to 99\% to 61 to 62\%~\cite{razmara2026takeover}. Closest to our work, Yan et al.~\cite{yan2026oneskill} found that nearly one in four installed skills had a similar co-installed skill, and that the installed skill was used 19.9 percentage points less often when one was present. Their inventory excludes other agents' directories and does not examine drift between copies.

\textbf{Code cloning and copy-based reuse.} Most files on GitHub have a duplicate~\cite{lopes2017dejavu}. Clones evolve independently~\cite{kim2005genealogies}, inconsistent changes to clones are a common source of faults~\cite{juergens2009clones}, and some copies are deliberate adaptations~\cite{kapser2008cloning}. For skills, 53\% of reused skills are never modified after adoption~\cite{gao2026registry}, skill clones are widespread across authors~\cite{zhu2026latent}, and 58.7\% of skills share a name with another skill~\cite{jia2026islands}. We apply the clone-drift lens to a new case: copies of one skill kept in parallel for different agents.
