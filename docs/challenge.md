## What follows for this repository

- The repository is public. The call asks authors to make "a best effort" not to reveal their identities, and
  asks reviewers not to look at commit histories. So: never cite or link this repository in the submission; share
  code for review through an anonymised mirror (the call recommends anonymous.4open.science); keep author names
  out of the documents (roles are used instead), and give the repository a neutral name.
- Never commit author names, e-mail addresses or other personal details of skill authors. Row-level files that name
  repositories (for example the skill-rot sampling frame) stay in `data/private/`, which is not committed; the paper
  reports aggregates.
- Before archiving on Zenodo, review every data file for personal information.
